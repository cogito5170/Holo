# 인터랙티브 홀로그램형 3D 디스플레이 연구·프로토타입 README

## 0. 목적과 성공 정의

이 프로젝트는 **고휘도 3D 시각화, 손 추적 기반 비접촉 터치, 초음파 햅틱**을 결합한 인터랙티브 디스플레이 프로토타입을 만든다. 여기서 “홀로그램”은 레이저로 공중에 실제 3차원상을 만드는 장치가 아니라, 사용자가 공중에 떠 있는 듯 인식하는 **안전한 입체 표시 시스템**을 뜻한다.

### 1차 프로토타입의 측정 가능한 목표

| 항목 | 1차 목표 | 검증 방법 |
|---|---:|---|
| 3D 모델 표시 | glTF/GLB 모델 1개를 30 fps 이상으로 표시 | 프레임 시간 로그 |
| 입체감 | 무안경 시차 또는 깊이감이 있는 광학 구조 | 사용자 관찰 시험 |
| 터치 | 가상 버튼 5개에서 오입력률 5% 이하 | 20명/각 25회 시험 |
| 햅틱 | 선택·클릭 시 촉각 피드백 | 지연시간·사용자 평가 |
| 주변광 | 500 lux 실내에서 식별 가능 | 조도계·대비 측정 |
| 상시 운전 | 24시간 연속 운전 시 치명적 오류 없음 | 전력·온도·재시작 로그 |
| 안전 | 레이저 무사용 또는 해당 안전 기준 검토 완료 | 광원/열/전기 점검표 |

> 직접 햇빛 아래 가시성, 매우 낮은 광량, 저가격, 24시간 운전은 동시에 최대로 달성하기 어렵다. 1차 목표는 **500 lux 실내 및 밝은 사무실**로 제한하고, 직사광선 환경은 별도 2차 목표로 둔다.

## 1. 연구 원칙

- 논문은 DOI·정식 인용 정보를 우선 저장한다.
- 유료·403 논문은 우회하지 않는다. OpenAlex, Unpaywall, arXiv, 기관 리포지터리의 합법적 공개본을 찾고, 없으면 초록·서지 정보만 기록한다.
- 논문 주장과 제품 사양을 분리한다. “논문에서 입증”과 “제조사 주장”을 같은 근거로 취급하지 않는다.
- 모든 수치에는 단위, 측정 조건, 출처, 날짜를 붙인다.
- 초음파, 고전압, 레이저, 회전부품은 안전 검토 전에는 최종 시스템에 연결하지 않는다.

## 2. 권장 개발 경로

```text
문헌 지형 파악
  → 요구사항·성능지표 확정
  → 후보 아키텍처 3개 비교
  → 부품/BOM 및 전력 예산
  → 화면·3D 렌더링 MVP
  → 손 추적·가상 터치
  → 햅틱 통합
  → 광학/기구 통합
  → 24시간·안전·사용성 시험
  → 데모와 재현 패키지
```

## 4. 단계별 프롬프트

아래 프롬프트에서 대괄호 부분만 프로젝트 사실로 바꿔 사용한다. AI의 답변은 초안이며, 원문·데이터시트·측정으로 검증해야 한다.

### 단계 A — 연구 질문과 범위 고정

**프롬프트 A1: 연구 브리프**

```text
당신은 디스플레이 광학, HCI, 임베디드 시스템을 아우르는 수석 연구원이다.
다음 목표를 검증 가능한 연구 브리프로 바꿔라.

목표: [3D 모델], [비접촉 터치], [초음파 햅틱], [특정 하드웨어 연동],
[24시간 운전], [밝은 실내 가시성], [안전], [저전력], [가격 효율].
제약: 예산 [금액], 크기 [가로×세로×깊이], 대상 사용자 [사용자],
주변광 [lux 또는 환경], 전원 [AC/DC/배터리], 개발 기간 [기간].

출력 형식:
1) 문제 정의 3문장
2) 반드시 만족할 요구사항과 있으면 좋은 요구사항
3) 정량 KPI와 측정법
4) 서로 충돌하는 요구사항과 조정안
5) 이번 프로토타입에서 제외할 항목
추정치는 ‘추정’이라고 표시하고, 안전 관련 가정을 분리하라.
```

**프롬프트 A2: 용어 정리**

```text
다음 용어를 이 프로젝트 문맥에서 혼동 없이 정의하라:
홀로그램, 라이트필드, 무안경 3D, 페퍼스 고스트, 볼류메트릭 디스플레이,
공중 초음파 햅틱, 가상 터치, 휘도, 조도, 대비, 광학 안전, 스페클.
각 항목에 ‘이 프로젝트에서 채택/비채택 여부’와 이유를 덧붙여라.
```

### 단계 B — 논문 탐색과 합법적 원문 확보

**프롬프트 B1: 검색 전략 생성**

```text
주제는 ‘안전하고 저전력인 인터랙티브 3D 디스플레이’다.
다음 6개 축별로 영어 Boolean 검색식을 3개씩 작성하라:
1. computational holography/light-field/autostereoscopic display
2. high-brightness/microLED/outdoor or ambient-light visibility
3. ultrasonic mid-air haptics
4. hand tracking/virtual touch/gesture interaction
5. low-power/thermal management/24-7 reliability
6. speckle/diffraction/interference robustness/eye safety

각 검색식에 적합한 데이터베이스(Optica, SPIE, IEEE Xplore, ACM DL, arXiv,
OpenAlex)와 포함·제외 기준을 표로 제시하라.
```

**프롬프트 B2: 논문 선별**

```text
아래 논문 메타데이터 목록을 체계적 문헌 검토의 1차 선별 방식으로 평가하라.
[제목, 초록, 연도, DOI, 링크를 붙여 넣기]

각 논문마다 다음 열을 채운 Markdown 표를 만들어라:
포함/보류/제외, 관련 축, 핵심 기여, 사용한 하드웨어, 정량 성능,
한계, 재현 가능성, 공개 원문 여부, 반드시 원문에서 확인할 주장.
초록에 없는 숫자는 절대 지어내지 말라.
```

**프롬프트 B3: 403 처리**

```text
다음 DOI/논문 목록에서 합법적 공개 접근 경로만 찾는 절차를 제시하라.
우선순위는 OpenAlex의 OA 위치, Unpaywall, arXiv, PubMed Central(해당 시),
저자·대학 리포지터리, 도서관 링크 리졸버다.
유료 원문이나 접근 거부는 우회하지 말고 ‘권한 필요’로 기록하라.
각 논문에 대해 DOI, 정식 출판 링크, 공개본 링크, 버전(preprint/AAM/VOR),
라이선스, 확인 날짜를 반환할 표의 빈 템플릿도 만들어라.
```

**프롬프트 B4: 근거 추출**

```text
다음은 한 논문의 발췌문/표/그림 설명이다.
[내용]

이 프로젝트의 의사결정에 쓸 수 있는 주장만 추출하라.
각 주장에 대해 (a) 정확한 수치와 단위, (b) 실험 조건, (c) 비교 기준,
(d) 한계, (e) 설계에 주는 의미, (f) 출처 페이지·그림·표를 기록하라.
출처에 없는 내용은 ‘추론’으로 별도 표시하라.
```

### 단계 C — 아키텍처 선택

**프롬프트 C1: 후보 설계 비교**

```text
다음 세 아키텍처를 비교해 의사결정 표를 만들어라.
A. 고휘도 2D/microLED + 반사 광학(페퍼스 고스트형)
B. 무안경 다안점/라이트필드 디스플레이
C. 레이저 기반 계산 홀로그램

평가 기준: 3D 품질, 밝은 실내 가시성, 전력, 가격, 24시간 신뢰성,
눈 안전, 회절/간섭·스페클 강건성, 터치/햅틱 통합성, 제작 난이도.
각 점수에 근거와 불확실성을 붙이고, [예산]과 [환경]에서 1차 MVP를 하나 추천하라.
```

**프롬프트 C2: 인터페이스 명세**

```text
선택 아키텍처는 [선택안]이다. 다음 모듈의 인터페이스 명세 초안을 작성하라:
렌더링 호스트, 디스플레이, 손 추적 센서, 햅틱 어레이, 조도 센서,
전력 관리, 안전 인터록, 로깅 시스템.
각 모듈에 전원, 데이터 인터페이스, 업데이트율, 지연 예산,
오류 상태와 fail-safe 동작을 표로 제시하라.
```

### 단계 D — 부품·원가·전력 예산

**프롬프트 D1: BOM 초안**

```text
[선택 아키텍처]의 MVP용 BOM을 작성하라.
필수 열: 부품, 요구 사양, 후보 2~3개, 단가 범위, 수량, 소계,
공급 위험, 대체품, 검증할 데이터시트 항목.
부품은 디스플레이, 광학부, 컴퓨팅 보드, 카메라/ToF, 햅틱, 전원,
방열, 기구, 케이블, 안전 부품으로 분류하라.
가격은 출처·통화·확인 날짜가 없으면 ‘미확인’으로 표기하라.
```

**프롬프트 D2: 전력·열 예산**

```text
다음 부품 소비전력 정보를 사용하여 평균/피크 전력 예산과 24시간 에너지,
전원 정격, 발열 위험을 계산하라.
[부품별 전압, 전류 또는 W, 듀티사이클, 동작 시간]

계산 과정과 단위를 보이고, 모르는 값은 변수로 남겨라.
온도 측정 위치, 허용 온도, 쓰로틀/차단 기준을 포함한 시험 계획도 제안하라.
```

### 단계 E — 구현

**프롬프트 E1: 소프트웨어 MVP 설계**

```text
다음 기능의 최소 구현 계획을 제시하라:
GLB 3D 모델 로딩, 실시간 렌더링, 손 좌표 수신, 가상 버튼 충돌 판정,
햅틱 이벤트 송신, 조도 기반 밝기 조절, CSV 로그.

플랫폼: [Unity/Unreal/WebGPU/Python/C++]
호스트: [PC/Jetson/Raspberry Pi 등]
출력은 모듈 경계, 데이터 흐름, 2주 단위 작업 순서, 핵심 의사코드,
단위시험 항목이다. 아직 확정되지 않은 SDK/API는 가정으로 표시하라.
```

**프롬프트 E2: 터치와 햅틱 상호작용**

```text
공중 가상 버튼의 상태기계를 설계하라.
상태: idle, hover, arm, activate, cancel, tracking-lost, safety-stop.
입력: 손 위치, 속도, 머무름 시간, 깊이, 신뢰도.
출력: 시각 피드백, 햅틱 패턴, 로그 이벤트.
오작동 방지를 위해 debounce, 경계 히스테리시스, 추적 상실 처리,
햅틱 강도 제한을 포함하고, 전이표와 의사코드를 작성하라.
```

### 단계 F — 광학·안전·기구 검증

**프롬프트 F1: 안전 검토표**

```text
이 시스템의 위험 분석(FMEA 초안)을 작성하라.
범위: 광원/눈 안전, 초음파 노출, 발열, 감전, 날카로운 기구물,
전원 장애, 센서 오인식, 소프트웨어 폭주, 24시간 무인 운전.
각 위험에 심각도·발생 가능성·탐지 가능성·완화책·운전 금지 조건을 제시하라.
법규 적합성을 단정하지 말고, 지역과 제품 용도에 따라 전문가 검토가 필요함을 명시하라.
```

**프롬프트 F2: 회절·간섭 리스크**

```text
선택한 광학 아키텍처에서 발생 가능한 회절, 간섭, 스페클, 고스트,
반사, 주변광 대비 저하를 분리해 설명하라.
각 현상에 대해 원인, 관찰 방법, 정량 지표, 저감책, 비용/전력 부작용을 표로 작성하라.
레이저를 쓰지 않는 구조에도 적용 가능한 항목과 레이저 전용 항목을 구분하라.
```

### 단계 G — 시험·판정·문서화

**프롬프트 G1: 시험 계획**

```text
다음 목표를 검증하는 시험 계획을 작성하라:
3D 프레임률, 지연, 터치 성공률, 햅틱 인지, 휘도/대비, 소비전력,
온도, 24시간 안정성, 오류 복구.

각 시험마다 장비, 환경, 표본 수, 절차, 기록할 원시 데이터, 합격 기준,
실패 시 다음 조치를 정의하라. 주관적 사용자 평가는 객관적 계측과 분리하라.
```

**프롬프트 G2: 결과 해석**

