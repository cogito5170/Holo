## 2. 운전 전 점검 (매 세션)

### 광원
- [ ] 레이저를 사용하지 않음 — 또는 사용 시 해당 레이저 안전 기준 검토 기록 첨부
- [ ] 최대 휘도 설정과 사용자 시선 위치 확인

### 초음파 햅틱
- [ ] 출력 강도 상한이 펌웨어에 고정되어 있음
- [ ] 노출 시간·거리 조건이 검토 기록과 일치
- [ ] 안전 검토 완료 전에는 사람 대상 시험 금지

### 전기·열
- [ ] 전원 정격이 `research/06-power-thermal.xlsx`의 필요 정격 이상
- [ ] 노출된 고전압부 없음, 접지 확인
- [ ] 사용자 접촉부 표면 온도가 허용 기준 이하
- [ ] 쓰로틀·차단 온도 동작 확인

### 기구
- [ ] 날카로운 모서리·돌출부 없음
- [ ] 광학 부품(반사판·유리) 고정 및 파손 시 비산 대책

### 소프트웨어·무인 운전
- [ ] 워치독 동작 확인 (폭주 시 햅틱·광 출력 정지)
- [ ] 추적 상실 시 safety-stop 전이 확인
- [ ] 무인 운전 중 원격 정지 수단 또는 현장 감독자 지정
